🛡️ AuthService
==================

Микросервис для аутентификации и авторизации пользователей, реализованный с использованием Spring Boot и JWT. 
Предоставляет REST API для регистрации пользователей, входа в систему и проверки JWT-токенов.

📌 Назначение проекта
==================

Проект предназначен для обработки пользовательской аутентификации в распределённых приложениях. AuthService можно использовать как часть большего микросервисного решения, предоставляя централизованный способ управления доступом и безопасности.

👾 Функциональность
==================

Регистрацию пользователей с сохранением в базе данных
Аутентификацию (вход) с выдачей JWT токена
Проверку токена и управление сессиями
Выход пользователя (logout)

🛠️ Используемые технологии
==================
```
Java 17+
Spring Boot
Spring Security, JWT (JSON Web Tokens)
PostgreSQL
Gradle (Kotlin DSL)

```
